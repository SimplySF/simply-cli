## One install

```sh
npm install -g @simplysf/simply-cli

simply gitlab mr list --project group/project
# Installing @simplysf/simply-gitlab to run gitlab:mr:list (first run only)…

simply atlassian jira issue search --jql "project = PROJ AND statusCategory != Done"
```

`simply --help` lists every product topic whether or not it is installed, so you can find a command
before anything is downloaded.

## Why one command

Each product CLI used to own `simply` itself, which meant only one could be installed at a time —
npm links one binary name to one package. A single host now owns the name and the products are
plugins, so they coexist, and adding a third changes nothing about the first two.

Your commands did not change. `simply gitlab mr list` and `simply atlassian jira issue view PROJ-42`
are what they always were.
